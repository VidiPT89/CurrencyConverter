# 💱 Currency Converter

> A modern, elegant and interactive currency converter built with HTML, CSS and vanilla JavaScript. Designed with a refined visual identity, bilingual support and a polished user experience.

Currency Converter is a lightweight web app that fetches live exchange rates and lets you convert between dozens of currencies in real time. The project combines a premium glassmorphic interface, animated transitions, offline-ready cached rates and a persistent conversion history in a simple and professional experience.

## ✨ Main Features

- 🌍 Convert between dozens of currencies using live exchange rates
- 🔄 Swap origin and destination currencies with a single click
- 📡 Fetch up-to-date rates from a public exchange rate API
- 📴 Fall back to cached rates automatically when offline
- 🕘 Keep a persistent history of recent conversions locally
- 🌍 Switch seamlessly between Portuguese and English
- 🎬 Enjoy smooth animated transitions and a live-updating result
- 🎨 Experience a modern dark interface with glassmorphism and floating gradients

## ▶️ How to Run

Open the project directly in your browser, or serve it locally with:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/
```
